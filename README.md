# Saurabh6912 Repository

This repository is a collection of hands-on projects focused on Generative AI, agentic systems, machine learning, and data science. It includes learning notebooks, practical experiments, and mini applications built with Python and modern AI tools.

## Project Areas

### GEN AI
This section covers practical learning in Generative AI and LLM-based development, including:

- LangChain and prompt engineering
- Embeddings and document similarity
- RAG pipelines and vector stores
- LangGraph workflows and agentic patterns
- Chatbot and tool-calling experiments
- PDF and document-based AI use cases

### Machine Learning - Deep Learning
This section includes a predictive analytics project for brain stroke risk assessment using machine learning and data visualization.

### Main Focus
- Learn core AI and ML concepts through real projects
- Build end-to-end workflows around LLMs and agents
- Apply data science to healthcare and prediction use cases
- Explore practical implementation using Python, notebooks, and APIs
